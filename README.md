# FactorySim Lab

**Python-Based Factory Simulation and Industrial Training Project**

## Overview

FactorySim Lab is an educational software project exploring how Python programming can model basic factory operations. The long-term goal is to develop an interactive learning platform for students and workforce training programs.

The current prototype demonstrates a simulated factory machine and its production status. Future development will expand the simulation with production tracking, machine states, performance metrics, and interactive training exercises.

## Project 1: Basic Factory Machine Simulation

This project is a working Python prototype that displays a simulated machine's name, operating status, and production count.

### Implemented Features

- Stores a factory machine's name using a Python variable.
- Represents the machine's operating status.
- Initializes a production counter.
- Displays simulation information using Python print statements.
- Runs in Google Colab using a Jupyter Notebook.

### Example Output

```text
Welcome to FactorySim Lab!
--------------------------
Machine: Assembly Machine 1
Status: Running
Products produced: 0
```

## Technologies and Tools

- **Python** — programming fundamentals and simulation logic
- **Google Colab** — browser-based Python development and testing
- **Jupyter Notebook** — interactive code and output
- **GitHub** — source code hosting, version history, and project documentation

## How to Run

1. Open `FactorySim_Lab_Project_1.ipynb` in this repository.
2. Open the notebook in Google Colab.
3. Run the code cell using the play button.
4. Review the output showing the machine name, status, and production count.

## Learning Objectives

This project provides practical experience with:

- Python variables, strings, integers, and print statements.
- Representing factory machine information in code.
- Running and verifying a Python program.
- Documenting software projects.
- Using GitHub to maintain a development portfolio.

## Planned Features

The following features are planned for future versions and have not yet been implemented:

- Production cycles that increase the product count.
- Machine operating states such as running, stopped, and maintenance.
- Production summaries and basic performance indicators.
- Simulated machine faults and troubleshooting activities.
- Interactive learning exercises for schools and workforce training programs.
- A web application, with potential future Android support.

## Project Status

**Current status: Initial working prototype completed.**

Project 1 runs in Google Colab and displays the expected output. Additional features will be developed, tested, and documented incrementally.

## Project Goals

FactorySim Lab aims to combine software development with manufacturing and workforce education. The long-term vision is to explore an accessible training tool that helps learners understand factory operations through practical simulation activities.
